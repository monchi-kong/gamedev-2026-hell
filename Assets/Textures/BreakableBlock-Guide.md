# 壊せるブロック

`BreakableBlock.asset` は専用の木製ブロックです。既存のblock2の絵を使いますが、通常タイルとは別のアセットです。

## 配置

Window > 2D > Tile Palette を開き、New Tile Palette を選びます。
既存のタイル列の左端から2マス下にある木製タイルが壊せるブロックです。
Active TilemapをステージのTilemapにして描いてください。
またはBreakableBlock.assetをパレットの空きマスへドラッグして登録できます。

Scene1には、セル(204, 2)、(205, 2)、(206, 2)にサンプルを配置しています。
現在のプレイヤー開始位置から少し右です。

## 動作

- 上昇中にブロックの底へ頭を当てると1個壊れます。
- 横から触れる・上に乗る・下から歩いて触れるだけでは壊れません。
- 通常の地面やタイルは壊れません。
- 壊れたタイルの当たり判定も更新します。
- 破壊状態の保存は行いません。シーンを読み直すと復活します。

## Unityでの確認項目

1. Scene1を再生し、少し右の3個をそれぞれ下からジャンプで壊す。
2. 上に着地した場合と横から当たった場合に残ることを確認する。
3. 通常の足場は下から叩いても残ることを確認する。
4. 2個の境目を叩いても同じ物理ステップで複数個壊れないことを確認する。
5. 再生を止めて再開し、3個が復活することを確認する。

コードのコンパイル・シーンの既存タイル保持・タイル参照数の整合性は確認済みです。
Unityの再生による上記操作確認は未実施です。
